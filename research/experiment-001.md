## 问题与假设

对同一条资产收益路径，每期开始保持 50% 风险资产、50% 现金，是否比 100% 风险资产降低波动率与最大回撤？收益会发生什么变化？

这是仓位效果实验。它不尝试证明选股或择时能力，也不从结果反推最佳仓位。

## 数据与规则

- 数据来源：本页预先写定的 10 期人工教学序列，无对应证券、日期或真实市场。
- 初始净值：两组均为 100。收益以小数计算，例如 2% 写作 0.02。
- A 组基准：始终 100% 持有同一风险资产。
- B 组：每期期初再平衡至 50% 风险资产，剩余 50% 现金。
- 本轮假设：现金收益为 0，允许任意细分份额，无杠杆、无交易成本、无税费，无入金出金。
- 每期目标仓位固定，不读取当期收益作决定，不做参数搜索。
- B 组是每期再平衡，区别于只在开始买入一半后不调整。
- 核心公式：`Vₜ = Vₜ₋₁ × (1 + w × rₜ)`，A 组 w=1，B 组 w=0.5。
- 计算过程保留完整精度，只在展示时四舍五入。单期收益标准差采用样本口径，最大回撤包含初始净值。

## 本样本可以得出的结论

本样本中，B 组的单期收益标准差恰为 A 组的一半，因为其每期收益恰好是 A 组的一半。最大回撤从 **11.6800%** 变为 **5.9200%**，不应把最大回撤也直接除以二。

两组的最大回撤都发生在第 3 期末峰值到第 5 期末谷值。A 组累计收益为 **0.2415%**，B 组为 **0.3126%**；降低仓位同时改变了收益路径，不能只看回撤一个数字判断优劣。

## 不能得出的结论

- 不能证明 50% 是最佳仓位，或这套方法存在超额收益。
- 不能把这 10 期数据当作市场历史，或据此计算可靠的年化表现。
- 不能把无成本的再平衡当作真实可执行策略。净值变化后，即使目标一直是 50%，实际仓位也会漂移，再平衡仍然产生交易。
- 不能认为现金收益、最小成交单位、滑点与交易制度对结果没有影响。

## 下一轮检验：先固定方案，再看结果

1. 在同一输入上比较不再平衡的 50% 初始仓位，区分仓位降低和再平衡效果。
2. 成本场景按单边成交额的 0、5、10 个基点分别计算（1 个基点 = 0.01%）。这是敏感性假设，不是任何券商报价；记录初始建仓与每次再平衡成本，两组采用相同口径。
3. 明确是否在末期清仓。本轮按市值计价，不模拟末期清仓；未来若清仓，应对两组同时扣除退出成本。
4. 在引入真实行情前，登记标的、数据供应方、起止日期、下载日期、复权与分红口径、缺失值规则、成交时点和市场约束，并保存可复现的数据摘要。

## 用 Python 标准库复算

下面代码无需安装第三方库，输出每日净值以及累计收益、样本标准差、最大回撤。输出顺序与上表一致。

```python
from statistics import stdev

returns = [0.02, -0.01, 0.03, -0.08, -0.04,
           0.05, 0.02, -0.03, 0.04, 0.01]

for weight in (1.0, 0.5):
    nav = [100.0]
    portfolio_returns = [weight * r for r in returns]
    for r in portfolio_returns:
        nav.append(nav[-1] * (1 + r))

    peak = nav[0]
    drawdowns = []
    for value in nav:
        peak = max(peak, value)
        drawdowns.append(1 - value / peak)

    print(f"目标仓位 {weight:.0%}")
    print("净值:", [round(value, 4) for value in nav])
    print(f"累计收益: {nav[-1] / nav[0] - 1:.4%}")
    print(f"单期样本标准差: {stdev(portfolio_returns):.4%}")
    print(f"最大回撤: {max(drawdowns):.4%}")
```
