## 1. 期望值与保本胜率

假设每笔结果只有盈利或亏损两种，p 为胜率，W 为平均毛盈利 R，L 为平均毛亏损幅度 R，c 为每笔完整交易的平均成本 R：

`净期望 E = p × W - (1 - p) × L - c`

令 E=0，得到：

`保本胜率 p* = (L + c) / (W + L)`

这是在 W、L、c 给定时的代数关系。实际盈亏和成本会变化，历史样本不能提供确定的未来胜率。如果存在保本交易，要增加其概率或直接对逐笔净 R 求平均。

例如 W=2、L=1、c=0.10，保本胜率为 **36.67%**。胜率 40% 时，毛期望 0.20R，净期望 0.10R。胜率 70%、平均赚 0.3R、平均亏 1R，毛期望反而为 **-0.09R**。

## 2. 盈亏比与利润因子不是一回事

- 平均盈亏比 = 平均盈利幅度 / 平均亏损幅度。
- 利润因子 PF = 所有盈利金额之和 / 所有亏损金额绝对值之和。
- 例：4 笔各赚 2R，6 笔各亏 1R，平均盈亏比 2，毛 PF 为 8/6≈1.333。
- 0 笔亏损时 PF 的分母为零，不应据此宣称无限可靠；样本可能太小。

不同交易的 R 金额不同，则 R 序列的 PF 与现金金额 PF 也可能不同。本课沿用固定 1R=200 元的样本，避免口径混淆。

## 3. Python：同一序列，三种成本

```python
gross_r = [2, -1, -1, 3, -1, 1.5, -1, -1, 2.5, -1]
risk_money = 200

def summarize(values):
    positive = [x for x in values if x > 0]
    negative = [x for x in values if x < 0]
    pf = sum(positive) / -sum(negative) if negative else None
    return sum(values)/len(values), len(positive)/len(values), pf

for cash_cost in (0, 10, 30):
    net_r = [r - cash_cost/risk_money for r in gross_r]
    expectation, win_rate, pf = summarize(net_r)
    print(f"完整交易成本={cash_cost}元, 净期望={expectation:.2f}R, "
          f"净胜率={win_rate:.2%}, PF={pf:.4f}")

p, win, loss, cost = 0.40, 2.0, 1.0, 0.10
expectation = p*win - (1-p)*loss - cost
break_even = (loss + cost)/(win + loss)
print(f"另一假设例: 净期望={expectation:.2f}R, 保本胜率={break_even:.2%}")
assert abs(expectation - 0.10) < 1e-12
```

样本净期望依次为 **0.30R、0.25R、0.15R**；PF 依次约为 **1.5000、1.3968、1.2174**。这里成本不足以把任何一笔盈利变成亏损，所以净胜率仍是 40%；在其他样本中净胜率可以下降。

## 4. 单边费率不是完整交易成本

“5 个基点” = 0.05% = 0.0005。假设买入成交额 10,000 元、卖出成交额 11,000 元，双边都按 5 个基点收费，则费用是：

`10000 × 0.0005 + 11000 × 0.0005 = 10.50 元`

这是教学费率，不是市场报价。若还有最低收费、买卖不同费率或其他税费，要逐项建模。

滑点最好反映在成交价里：买得略贵、卖得略便宜。若成交价已经调整过滑点，不要再把同一份滑点费用重复扣除。

## 5. 练习与进阶

- 把样本每笔完整交易成本改为 60 元；此时净期望应为 0R/笔。
- 加入一笔毛收益 0.02R 的小盈利，再扣 10 元，观察其净结果变成 -0.03R。
- 将同样 10 个 R 结果重新排序：总盈亏与平均期望不变，但逐笔权益的最大回撤可能变化。解释为什么只看平均数不够。
- 进阶：分别报告成本前后收益、交易次数、每笔平均净收益与最大回撤，不只看最漂亮的指标。

3. 样本均值为正能证明策略未来有效吗？
