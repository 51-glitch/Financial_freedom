## 怎样学习一课

1. 先读目标和算例，不运行代码，写下预计结果。
2. 运行完整代码，对照教材输出。
3. 修改一个指定条件，解释结果为什么改变。
4. 不看答案做自测，把错误和仍不理解的地方记下来。
5. 自己确认完成后再记录状态。助手执行代码只说明示例经过检查。

## 运行说明与计算口径

- 使用 Python 3。第8、9、11课需要 pandas；第7、10、12课只用标准库。
- 本轮所有6个Python示例已在 Python 3.12、pandas 2.2.3 环境运行。其他环境应记录实际版本，不能将最新官网文档版本当成本地安装版本。
- 示例使用内存中的人工数据，无需行情下载、账户、API密钥或付费订阅。
- 第7课是固定金额1R的逐笔平仓权益；第11课是含浮动市值的收盘权益，观测频率不同，不能直接比较两个最大回撤判断优劣。
- 旧手册第3课曾用总体标准差；本库风险笔记和实验001用样本标准差。两者分母不同，复算前先确认口径。
- 仓库Markdown可在GitHub或Obsidian直接阅读，答案折叠展示。此目录是仓库教材，不覆盖现有HTML手册或浏览器本地打卡记录。
