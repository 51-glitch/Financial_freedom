## 2. 手算 10 笔交易

固定教学序列：`[2, -1, -1, 3, -1, 1.5, -1, -1, 2.5, -1]`，单位为毛收益 R。每笔 1R 固定为 200 元，初始权益 20,000 元，每笔完整交易总成本 10 元。这里不是每笔按更新后的权益重新计算风险。

- 4 笔盈利，胜率 40%；总盈利 9R，平均盈利 2.25R。
- 6 笔亏损，总亏损 6R，平均亏损幅度 1R。
- 毛期望：`0.4 × 2.25 - 0.6 × 1 = 0.30R/笔`。
- 总毛利润 3R = 600 元，总成本 100 元，净利润 500 元，期末权益 20,500 元。
- 净收益率 2.5%；净期望为 0.25R/笔。

这里的“期望”是样本平均结果，不是已知的未来真实期望。10 笔正收益也不能排除运气。

## 3. Python 综合体检

只用 Python 标准库。先手算再运行，留意最大回撤包含初始权益。下面只观察逐笔平仓后的权益，无法捕捉持仓期间更深的浮亏。

```python
initial = 20000
risk_money = 200
r_results = [2, -1, -1, 3, -1, 1.5, -1, -1, 2.5, -1]

def review(cost_per_trade):
    equity = [float(initial)]
    for r in r_results:
        equity.append(equity[-1] + r * risk_money - cost_per_trade)
    peak = equity[0]
    mdd = 0.0
    for value in equity:
        peak = max(peak, value)
        mdd = max(mdd, 1 - value / peak)
    return equity[-1], equity[-1] / initial - 1, mdd

wins = [r for r in r_results if r > 0]
losses = [r for r in r_results if r < 0]
print(f"胜率: {len(wins)/len(r_results):.2%}")
print(f"平均盈利: {sum(wins)/len(wins):.2f}R")
print(f"平均亏损幅度: {-sum(losses)/len(losses):.2f}R")
for cost in (10, 30):
    end, total, mdd = review(cost)
    print(f"成本 {cost} 元: 期末 {end:.2f}, 净收益 {total:.2%}, 最大回撤 {mdd:.4%}")
assert review(10)[0] == 20500
assert review(30)[0] == 20300
```

核对结果：10 元成本时最大回撤约 **2.0598%**；30 元时约 **2.2582%**。两次比较使用同一组毛 R，不能在提高成本时偷偷更换交易。

## 4. 练习：把观点变成可验证问题

教学情境：“某板块连续两天上涨，可能形成趋势。”这不是当前行情判断。

请先写观察窗口，再写支持与失效条件，例如：在固定的后续观察窗口内，与事先选定的基准比较累计收益，同时记录上涨家数比例和成交量。具体阈值必须在看结果前确定；不能后来把两天改成十天，只为保住原观点。

用四句话记录：看到了什么事实、原先预期是什么、价格怎样反应、下一步用什么证据判断。没有市场数据时只写研究方案，不补造结果。
