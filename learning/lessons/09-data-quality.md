## 1. 一行数据不只有一个日期

行情至少要区分：所属交易时段、数据发布或可获取时间、策略计算时间、可成交时间。财报属于第一季度，不代表季度末就能知道财报数字；后来的修订值也不等于历史上当时公布的值。

研究前保留一份数据说明：

| 字段 | 要记录什么 |
| --- | --- |
| 标的与市场 | 代码、交易场所、币种，不能只凭简称 |
| 来源 | 原始文件或接口、下载时间、版本 |
| 时间 | 时区、交易日历、时段、字段可获取时间 |
| 价格 | 原始价、复权价、分红和拆股怎样处理 |
| 异常 | 缺失、重复、停牌、退市、无成交记录怎样处理 |
| 范围 | 起止日期、数据筛选条件、原始文件校验值 |

本课不把人工数据改名为“真实行情”。引入真实数据时再填写这些字段。

## 2. 三类容易让结果变漂亮的错误

**前视偏差**：在过去使用未来才知道的信息。例如用明天的价格填今天的缺失，用当日最终收盘价产生信号后又假定已经按同一收盘价成交。

**幸存者偏差**：只用今天还存续的公司回测历史，漏掉已经退出的公司。标的池也需要尽量还原当时的状态。

**复权和现金流口径混乱**：例如把含分红调整的总回报数据再加一次现金分红，造成重复计算。指标可以使用明确口径的调整序列，但实际订单、份额和现金账必须一致。

## 3. 窗口到底包含哪几天？

教学收盘价为 `[100, 101, 102, 104, 103, 105]`。第 4 个收盘价为 104，之前 3 个收盘价最高为 102，所以产生突破信号。

“过去 3 日最高收盘价”必须排除当前这一行。使用 `shift(1).rolling(3).max()`，先向后移动，再滚动计算；窗口不足 3 个值时不交易。

```python
import pandas as pd

close = pd.Series([100, 101, 102, 104, 103, 105], dtype=float)
def make_signals(series):
    past_high = series.shift(1).rolling(3, min_periods=3).max()
    signal = series.gt(past_high) & past_high.notna()
    return pd.DataFrame({"close": series, "past_high": past_high, "signal": signal})

original = make_signals(close)
print(original)
assert original["signal"].tolist() == [False, False, False, True, False, True]

# 只改未来第6个价格，前5个时间点的指标和信号不应变化。
changed = close.copy()
changed.iloc[5] = 1000
pd.testing.assert_frame_equal(
    original.iloc[:5], make_signals(changed).iloc[:5]
)
print("未来扰动检查通过")
```

期望第 4—6 行的 past_high 为 102、104、104。这是因果性的一项检查；通过它不代表数据供应方、标的池与成交模型都已经正确。

## 4. 缺数据时怎样决定？

先问缺失的原因，再定义规则：

- 完全重复且来源相同的记录可以去重；冲突记录应停下核对。
- 非交易日通常不是缺行情，不能为了凑每天一行就虚构成交。
- 真实交易日缺价格时，先暂停相关信号计算。估值是否沿用旧价需要单独记录，沿用估值不等于允许按旧价成交。
- 多个数据表合并时，要按“当时已公布”匹配，不能把未来报告回填到所属季度。

## 5. 实践与进阶

手写一张 6 行表，逐行列出当天可见价格和过去 3 日最高价。然后故意把 `shift(1)` 去掉：当日 close 不可能严格大于包含自身的最高值，信号逻辑会发生什么？

再做一个思考实验：修改最后一天价格，观察一个使用全样本平均数的规则是否会改变早期信号。它可能没有显式使用“明天”，但仍可能泄漏未来信息。

2. 复权价格和原始成交价能否不作说明地混用？
3. 未来扰动检查通过是否等于已经消除所有偏差？
