# 风险与仓位：从概念到复算

[返回首页](../README.md) · [学习路线](roadmap.md) · [实验 001](../research/experiment-001.md)

整理日期：2026-10-23。以下金额和行情全部是教学示例。

## 1. 收益率与复利

没有追加或提取资金时，单期收益率：

`r = 期末净值 / 期初净值 - 1`

多期累计收益率：

`累计收益 = (1 + r₁) × (1 + r₂) × … × (1 + rₙ) - 1`

例如 100 元先涨 10%、再跌 10%，变成 99 元，累计收益为 **-1%**，不是 0%。有入金、出金时，应先处理现金流，不能直接把账户余额变化全部当作投资收益。

## 2. 波动率与标准差

波动率描述收益变化的幅度，既包含向上也包含向下的变化。先计算各期收益，再对收益序列计算标准差，不能拿价格标准差直接比较不同价格的资产。

本库教学实验默认使用样本标准差：

`s = sqrt(Σ(rᵢ - 平均收益)² / (n - 1))，n ≥ 2`

使用 NumPy 时显式写 `ddof=1`；其默认值为 0，采用的分母不同。参见 [NumPy 官方说明](https://numpy.org/doc/stable/reference/generated/numpy.std.html)。

日波动率按 `s × sqrt(252)` 年化只是约定与假设下的换算：252 是常见股票交易日近似值，且需要考虑收益相关性和波动变化。实验 001 只有 10 期教学数据，因此不报告年化指标。

## 3. 最大回撤

先把收益连乘成净值序列，并包含初始净值：

`历史峰值 Hₜ = max(V₀, V₁, …, Vₜ)`

`回撤 Dₜ = 1 - Vₜ / Hₜ`

`最大回撤 MDD = max(Dₜ)`

本库把回撤写成非负数。净值 100 → 120 → 90 → 110，最大回撤为 `1 - 90/120 = 25%`。末期仍赚 10%，与中途最大回撤 25% 并不矛盾。

从 25% 的亏损恢复到原峰值，需要上涨 `1/0.75 - 1 ≈ 33.33%`。历史最大回撤也不是未来损失的上限。

## 4. 仓位比例与风险预算

以现金买入普通股票的简化例子说明：

- 账户权益 E：20,000 元。
- 买入价 P：50 元；计划止损价 S：48 元。
- 单笔计划风险比例 f：0.5%，风险预算 B = E × f = 100 元。
- 每股计划风险 P - S = 2 元。
- 暂忽略成本与最小成交单位时，股数 q = floor(B / (P - S)) = 50 股。
- 资金占用 q × P = 2,500 元，仓位比例为 **12.5%**。

**0.5% 是计划风险比例，12.5% 是资金仓位比例。** 两者不同，示例参数不是实盘建议。

同时检查现金约束与风险约束：

`q ≤ 可用现金 / 买入价`

`q × (买入价 - 止损价) + 预计相关成本 ≤ 风险预算`

若最小买入单位是 100 股，50 股不可执行；100 股对应计划价差损失 200 元，已经超过原预算。不能为了凑单位直接上调股数。可放弃这笔交易，或先重新评估规则；不要把不成交的假设仓位记为真实持仓。

止损价是计划退出位置，不保证成交价格。跳空和滑点会使实际亏损超过预算。多笔相关持仓还需要合并考虑账户风险。

## 5. R 倍数

在入场前固定初始计划风险金额，作为 1R；不能在亏损之后改写分母。

`已实现 R 倍数 = 扣除相关成本后的实际盈亏 / 初始计划风险金额`

以上例的 100 元为 1R：

| 净盈亏 | R 倍数 |
| --- | --- |
| +300 元 | +3R |
| -100 元 | -1R |
| -300 元 | -3R |

如果 300 元是扣成本前收益，而成本为 10 元，结果是 **+2.9R**。初始风险是否包含预计成本应事先写清，比较记录时必须保持同一口径。

## 6. 成本与策略规则

手续费、滑点与交易频率都会影响净收益；按成交额计费时还要考虑每次实际换手，而非只看期末仓位。[Investor.gov 关于费用影响的说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/updated)可作为基础参考；具体成本仍需按市场与账户规则定义。

把一个交易想法写成规则，至少回答：

1. 使用什么数据，在什么时间能够看到？
2. 信号什么时候计算，什么时候成交？
3. 买多少，现金不足或最小单位不满足时怎么办？
4. 何时退出，成交失败或缺数据时怎么办？
5. 成本如何计算，与什么基准比较？

## 7. 三道复习题

1. 100 元先涨 20%，再跌 20%，最后多少钱，累计收益多少？
2. 净值 100 → 110 → 88 → 105，最大回撤与末期收益分别多少？
3. 使用本页 50 元买入、48 元计划止损的示例：50 股资金仓位多少？若净赚 300 元是多少 R？若市场要求最少买 100 股，原方案能否直接执行？

## 常见错误与个人记录

| 常见错误 | 正确检查方式 |
| --- | --- |
| 把多期涨跌幅直接相加 | 连乘每期的 1 + 收益率 |
| 把最大回撤当作当前亏损 | 分别计算历史峰谷与期末净值 |
| 把仓位比例当作亏损比例 | 结合入场价、退出价和成本计算 |
| 只写“赚了 3R”，不写风险金额 | 保留入场前的 1R 定义与净盈亏 |
| 认为止损一定只亏 1R | 检查跳空、滑点和实际成交 |
